# Nadeck Bot

Telegram-бот поддержки. Это тонкий транспорт: сам он не хранит базу знаний и не вызывает OpenAI — каждое сообщение пересылается на backend (`POST /api/chat`), тот же эндпоинт, что использует AI-виджет на сайте. Поэтому база знаний, промпт и модель всегда одни и те же для обоих каналов.

FAQ-парсинг (сборка базы знаний из HTML-экспортов) теперь живёт в backend'е — см. `../nadeck-backend/scripts/parseFaq.ts`.

## Как это работает

На каждое сообщение бот шлёт POST на `${BACKEND_URL}/api/chat` с текстом вопроса и историей переписки этого чата (в памяти процесса, до 10 последних пар вопрос-ответ), получает готовый ответ и пересылает его в Telegram.

Все диалоги логируются в `data/logs/conversations.jsonl` (вопрос, ответ) — для контроля качества.

## Запуск

```bash
npm install
# .env общий для всей монорепы — лежит в корне репозитория (см. ../../.env.example)
# backend должен быть запущен и доступен по BACKEND_URL (по умолчанию http://localhost:3001)
npm run bot
```

## Настройка

Через корневой `.env` репозитория (не свой файл в этой папке):
- `TELEGRAM_BOT_TOKEN` — токен бота.
- `BACKEND_URL` — адрес backend'а (по умолчанию `http://localhost:3001`; в docker-compose — `http://backend:3001`).

Модель, температура, промпт и база знаний настраиваются в backend'е (`../nadeck-backend/src/chat/chat.service.ts`, `../nadeck-backend/scripts/parseFaq.ts`), не здесь.
