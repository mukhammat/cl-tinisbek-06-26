# Gender Router Bot

Отдельный Telegram-бот для общего чата. Когда в чат заходит новый участник, бот присылает
приветствие с кнопками «👨 Мужчина» / «👩 Женщина» и по нажатию отправляет ссылку на
соответствующий чат (мужской или женский).

Это отдельный бот от `nadeck-bot` (тот — транспорт для AI-консультанта на сайте). У этого своя
задача и свой токен.

## Как это работает

1. Бот должен быть добавлен в общий чат (админом чата, вручную через Telegram).
2. При входе нового участника Telegram присылает боту служебное сообщение
   `new_chat_members` — это происходит независимо от настройки Privacy Mode у бота
   (она ограничивает только обычные текстовые сообщения от других участников, не
   системные события вроде входа/выхода).
3. Бот отвечает в чате сообщением с двумя inline-кнопками. Кнопки привязаны к id
   присоединившегося пользователя — нажать может только он, для остальных участников
   кнопка ответит алертом «Эта кнопка не для вас».
4. По нажатию бот редактирует своё сообщение, убирает кнопки и показывает ссылку на нужный чат.

Все события (кого встретили, кто куда пошёл) логируются в `data/logs/routing.jsonl`.

## Запуск

```bash
npm install
# .env общий для всей монорепы — лежит в корне репозитория (см. ../../.env.example)
npm run bot
```

## Настройка

Через корневой `.env` репозитория:
- `GENDER_BOT_TOKEN` — токен этого бота (создать через @BotFather, `/newbot`).
- `MALE_CHAT_LINK` — инвайт-ссылка на мужской чат (например `https://t.me/+xxxxxxxx` или
  `https://t.me/male_chat`, если это публичный чат/канал).
- `FEMALE_CHAT_LINK` — инвайт-ссылка на женский чат.

Токен и ссылки — не про код, это конкретные значения под ваш чат/боты, их нужно завести
самостоятельно (BotFather для токена, «Пригласить в группу по ссылке» для инвайт-ссылок) и
вписать в `.env`.
