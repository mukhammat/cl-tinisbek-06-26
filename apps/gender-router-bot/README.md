# Gender Router Bot

Отдельный Telegram-бот для общего чата. Когда в чат заходит новый участник, бот присылает
приветствие с кнопками «👨 Мужчина» / «👩 Женщина» — по нажатию кнопка сразу открывает
соответствующий чат (мужской или женский), без промежуточных шагов.

Это отдельный бот от `nadeck-bot` (тот — транспорт для AI-консультанта на сайте). У этого своя
задача и свой токен.

## Как это работает

1. Бот должен быть добавлен в общий чат (админом чата, вручную через Telegram).
2. При входе нового участника Telegram присылает боту служебное сообщение
   `new_chat_members` — это происходит независимо от настройки Privacy Mode у бота
   (она ограничивает только обычные текстовые сообщения от других участников, не
   системные события вроде входа/выхода).
3. Бот отвечает в чате сообщением с двумя inline-кнопками типа `url` — Telegram открывает
   ссылку сразу по нажатию, на стороне клиента, без обращения к боту. Это значит, что нажать
   может кто угодно (не только сам новый участник) и бот не узнаёт, кто что выбрал.

Факт приветствия (кого встретили) логируется в `data/logs/routing.jsonl`.

## Запуск

```bash
npm install
# .env общий для всей монорепы — лежит в корне репозитория (см. ../../.env.example)
npm run bot
```

## Настройка

Через корневой `.env` репозитория:
- `GENDER_BOT_TOKEN` — токен этого бота (создать через @BotFather, `/newbot`).
- `MALE_CHAT_LINK` — инвайт-ссылка на мужской чат (например `https://t.me/+xxxxxxxx` или
  `https://t.me/male_chat`, если это публичный чат/канал).
- `FEMALE_CHAT_LINK` — инвайт-ссылка на женский чат.
- `MALE_CHAT_LINK_AR` / `FEMALE_CHAT_LINK_AR` — инвайт-ссылки на арабские мужской и женский
  чаты. Если не заданы, арабское приветствие ведёт в те же чаты, что и русское (бот
  предупреждает об этом при старте).
- `GENDER_BOT_LANG` — язык по умолчанию: `ru` или `ar` (по умолчанию `ru`).
- `GENDER_BOT_CHAT_LANGS` — язык для конкретных чатов, через запятую:
  `-1001234567890:ar,-1009876543210:ru`.

## Язык приветствия

Тексты лежат в объекте `MESSAGES` в `src/bot.ts` (сейчас `ru` и `ar`). Язык выбирается так:

1. `GENDER_BOT_CHAT_LANGS` — если для этого чата задан язык явно, берётся он;
2. иначе — язык Telegram-клиента нового участника (`language_code`), если для него есть тексты;
3. иначе — `GENDER_BOT_LANG`.

Для арабской группы надёжнее пункт 1: язык клиента у участников бывает какой угодно, а
приветствие должно быть на языке группы. `chat_id` группы бот печатает в лог, когда его
добавляют в чат (событие `my_chat_member`), — например
`Бот в чате "Общий чат": chat_id=-1001234567890, статус=administrator, язык=ar`.

Если задать `GENDER_BOT_LANG=ar` и не заполнять `GENDER_BOT_CHAT_LANGS`, бот будет писать
по-арабски всем, у кого клиент не на русском.

Кнопки ведут туда же, куда указывает язык: арабское приветствие — в `MALE_CHAT_LINK_AR` /
`FEMALE_CHAT_LINK_AR`, русское — в `MALE_CHAT_LINK` / `FEMALE_CHAT_LINK`. Набор ссылок один на
язык, а не на чат: две русские группы будут вести в одни и те же мужской/женский чаты.

Токен и ссылки — не про код, это конкретные значения под ваш чат/боты, их нужно завести
самостоятельно (BotFather для токена, «Пригласить в группу по ссылке» для инвайт-ссылок) и
вписать в `.env`.
